# Calculator

A simple and interactive web-based calculator built with **HTML**, **CSS**, and **JavaScript**.

## Live Demo

Try it out here: [Calculator Live](https://wengelley.github.io/calculator/)

## Features

## Core Calculator Functions

- Addition, subtraction, multiplication, division

- Decimal support

- Delete last character

- Full clear (CLR)

## Scientific Functions

- log(x) — Common logarithm (base 10)

- ln(x) — Natural logarithm (base e)

- sqrt(x) — Square root

- exp(x) — Exponential function

- ^ — Power/exponent operator

## Display Persistence

- When switching between first and second calculator pages:

- Current display is saved

- Last calculation is saved

- Both are restored when you return

## Smart Display Scaling

- If the input text gets long, the calculator:

- Shrinks the font automatically

- Moves text to a new line when needed

## Auto Parentheses Fix

- If you forget a closing ), the calculator automatically adds it so the expression evaluates properly.

## History Saving

- Every calculation is saved to localStorage

- Last result is shown when you open the page

## Technologies Used

- HTML5

- CSS3

- JavaScript (ES6)

- Math.js library (for accurate evaluations)
